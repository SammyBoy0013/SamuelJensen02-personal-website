# Phase 5: Media, polish and SEO

Branch: `phase-5-polish`.

1. Gallery: move the images in `public/media` into Vercel Blob through the admin, or seed them there. Set up a lightbox with keyboard controls, and lazy-load images with dominant-colour placeholders.
2. Video: confirm muted autoplay, the unmute button, pausing off screen and poster images on every video.
3. Motion pass: check every transition, parallax and fade against specification 5.2, and the reduced-motion fallbacks.
4. Accessibility pass: alt text, focus states, keyboard navigation through the ribbon, dropdowns and drawer, and AA contrast. Fix anything that fails.
5. Performance: aim for Lighthouse 90+ in Performance, Accessibility, Best Practices and SEO on Home, Rowing and Golf (mobile). Report the scores.
6. SEO: `sitemap.xml` with `hreflang` alternates for all three languages, canonical URLs, Open Graph and Twitter tags with the share image on every page.
7. Check that the share image, favicon and page titles look right when a link is pasted into LinkedIn and WhatsApp (use the LinkedIn Post Inspector instructions for Samuel).

Write the phase report, then open a pull request.
